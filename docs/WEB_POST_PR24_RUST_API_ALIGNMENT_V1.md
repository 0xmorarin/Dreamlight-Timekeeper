## Concrete Phase A gaps and bounds

| Concern | Wand Rust research current behavior | WEB port decision |
| --- | --- | --- |
| Session | `open_decoded_research(session_id:u64,decoded_json:Vec<u8>,schema:u64,refs)`, caller-supplied research session number; `Arc<[u8]>` decoded JSON source SHA | UI's proposed Core-issued string SessionKey and source SHA **must have explicit SHA scope and trusted Worker provenance**. Never treat decoded JSON hash as original encrypted P1G SHA. Domain semantic graph must be built/validated by Core, not trusted from UI. |
| Source/build | Rust validates `GameInfo.Version` matches schema but does not open a P1G or validate externally selected Nintendo Switch BID | Existing JS Worker keeps source SHA and BID checks. Shared Core must expose **separate version/schema/BID evidence**, full P1G header/ZIP/AES/CRC, and positive per-operation capability before any write. |
| Projection | `query_paged(&[String],cursor:usize,limit:usize)`, `MAX_PAGE=64`, pointer watch <=512, preview raw JSON capped 512 bytes; skips unknown pointers with `filter_map` | Proposed `ProjectionQuery` domain/view/opaque cursor is **NOT implemented**. Core must issue revision-bound cursor with index-generation or equivalent, represent missing pointers, return complete/nextCursor and verified domain index provenance; do not simulate full-domain completion from a pointer subset. No UI raw full profile. |
| Index | `index_generation` increments on stage/undo/redo and lazy cached spans rebuild | This is research evidence for invalidation, not a stable async/Worker cursor. Session/Source SHA/Revision/Index generation must bind an accepted page/cursor response. |
| ChangeSet | `stage_command(TransactionPlan)` commits research mutation immediately, with `session_id`, expected revision/SHA, raw JSON pointer read witnesses and asserted `post_references`; `ChangeSet` has from/to revision, paths, identities | Future `planCAS` and `ChangeSetReference` use IDs/states, operation-specific meaning and Core-owned references; the current research interface has neither delayed plan/commit separation nor product semantic guards. Rust explicitly warns asserted graph **must never originate from untrusted UI**. No direct TS serialization of arbitrary replacement tokens or reference graphs. |
| Undo/Redo | Monotonic `undo(expected_revision)` / `redo(expected_revision)`, history max128, single research session | Good shape for shared revision; no product cross-domain semantic authority/Worker lifetime, persisted backing, cancellation or identity proof. Do not fork screen-specific history. |
| Validate | `validate_transaction()` checks JSON, SHA and asserted graph, returns `semantic_domain_guards_accepted:false` | `references_internally_consistent:true` is **not** a provenance/semantic validator. UI shall not infer a positive capability. |
| Backup | Rust `source` holds decoded JSON and its hash | Original encrypted P1G bytes/backup API absent. Timekeeper original-first byte-exact backup stays on unchanged legacy Worker. |
| Export | `export_verified_copy()` returns `PRODUCT_P1G_ENCODE_COPY_NOT_AUTHORIZED`; receipt `encode_copy_authorized:false`, `persistent_replace_authorized:false` | Product Rust `encodeCopy` unavailable. Existing independently checked **JS** encrypted P1G Encode/Reopen remains the oracle, not Rust permission. |
| Transport | Rust research library methods; no frozen production wasm32 Worker SaveSession protocol | No `openLocal/queryPage/planCAS/validate/history/backupOriginal/encodeCopy` network- or postMessage-compatible implementation. No UI-controlled feature flag enabling research WASM. |

**Safe future seam:** The `src/lib/timekeeper/save-session-contract.ts` port from PR24 remains design-only; `session-response-fence.mjs` rejects stale/mismatched replies **only after** a trusted Worker owns issuance. Shape validation alone is NOT authentication. Existing `timekeeper.save-worker@1` must continue handling the local encrypted source with Session/planRevision, original/edited distinct names, independently verified single Encode, and original-first downloads. No real paged Worker or shared Rust global change history has been implemented.
